# NUEDC 全国大学生电子设计竞赛 (TI杯) 全能解题技能

> **AI 代理全流程解题框架** — 赛题拆解 → 方案设计 → 器材选型 → 引脚级接线 → 代码生成 → 编译烧录 → 调试验证
> 只需告诉 agent 赛题编号（如 "2025年A题"），其余全部包揽

---

## 📋 一、技能总览

### 1.1 这个技能能做什么

| 操作 | agent 是否可完成 | 使用的工具/技能 |
|------|:---:|------|
| 赛题理解与拆解 | ✅ | web_search + 解析引擎 |
| 方案设计 | ✅ | 推理 + 赛题模板库 |
| 元器件选型 | ✅ | TI 芯片列表 + 选型规则 |
| **MCU 引脚/时钟/外设配置** | ✅ | `cubemx` 技能 (CubeMX2 CLI) |
| **模拟电路仿真验证** | ✅ | `ltspice` 技能 (SPICE 批处理) |
| **FPGA 逻辑仿真** | ✅ | `modelsim` 技能 (Verilog/VHDL) |
| **FPGA 综合/布局/下载** | ✅ | `quartus` 技能 (全流程编译) |
| 原理图/接线图生成 | ✅ | SVG 动态接线图 + `kicad` 原理图 |
| MCU 代码编写 | ✅ | HAL 库 + CubeMX 生成代码框架 |
| MCU 编译 | ✅ | `keil5` 技能 (UV4 CLI) |
| MCU 烧录 | ✅ | ST-Link/J-Link/pyOCD |
| PCB 设计 | ✅ | `kicad` 技能 (原理图→布线→Gerber) |
| 手动接线 | ❌ | agent 提供精确图文指导 |
| 焊接 | ❌ | agent 提供焊接指导 |
| 元件插拔 | ❌ | 需要人手操作 |
| 仪器操作 | ❌ | agent 提供示波器/万用表使用指导 |

### 1.2 调用方式

```bash
# 直接调用 nuedc 技能（推荐）
run_skill("nuedc", arguments="2025年A题 能量回馈的变流器负载试验装置")

# 专项子任务可调用其他技能
run_skill("cubemx",   arguments="根据赛题需求生成 STM32F103C8T6 引脚配置")
run_skill("ltspice",  arguments="仿真 Buck 电路 12V→5V，验证效率≥85%")
run_skill("modelsim", arguments="仿真 FPGA PWM 模块，验证占空比精度")
run_skill("quartus",  arguments="综合 FPGA 工程，生成 EP4CE6 的 .sof 文件")
run_skill("keil5",    arguments="编译并烧录 nuedc_test.uvprojx")
run_skill("kicad",    arguments="从原理图生成 PCB Gerber 文件")
```

### 1.3 按赛题类型自动路由工具

| 赛题类别 | 主控类型 | 仿真工具 | 代码工具 | PCB |
|----------|:--------:|:--------:|:--------:|:---:|

| **综合测评** | 纯模拟 | `ltspice` (运放/滤波) | — | — |

### 2.2 赛题结构解析模板

每道赛题按以下维度拆解：

```
赛题编号: [年份][题号] [题目名称]
────────────────────────────────────────
1. 任务描述
   └─ 核心功能: [一句话概括]
2. 技术指标
   ├─ 基本要求: [必须完成的 N 项]
   │  ├─ 指标1: [具体参数]
   │  ├─ 指标2: [具体参数]
   │  └─ ...
   └─ 发挥部分: [加分项 N 项]
      ├─ 发挥1: [具体参数]
      └─ ...
3. 评分标准
   ├─ 基本要求得分: [分值分布]
   └─ 发挥部分得分: [分值分布]
4. 元器件清单
   ├─ TI 推荐芯片: [型号列表]
   └─ 必备用具: [清单]
```

### 2.3 赛题分类与应对策略

| 类别 | 典型赛题 | 核心技能 | 常用 TI 芯片 |
|------|---------|---------|-------------|
| **电源类** | 三相AC-DC、DC-DC变换器、UPS | 功率拓扑、PWM、反馈控制 | LM5117, TPS5430, UCC28xxx |
| **控制类** | 智能小车、飞行器、机械臂 | PID、传感器融合、电机驱动 | MSPM0, TMS320F28xxx |

| **无人机类** | 植保飞行器、绕障飞行 | 姿态解算、光流、GPS | TMS320F28xxx, MSPM0 |

## 🧠 三、赛题拆解与方案生成工作流

### 3.1 工作流总图

```
用户输入赛题
     ↓
[步骤1] 解析赛题 → 提取技术要求、指标、评分点
     ↓
[步骤2] 方案设计 → 系统框图、模块划分、芯片选型
     ↓                ┌───── 模拟电路? ──→ [2a] ltspice 仿真验证
     ↓                ├───── FPGA逻辑?  ──→ [2b] modelsim 功能仿真
     ↓                └───── MCU项目?   ──→ [2c] cubemx 引脚/时钟配置
     ↓
[步骤3] 引脚分配 → 精确到每个引脚的连接关系
     ↓
[步骤4] 生成接线图 → SVG 动态接线图 + kicad 原理图
     ↓
[步骤5] 生成代码 → CubeMX 生成 HAL 框架 + 用户业务逻辑
     ↓                ┌───── STM32?  ──→ keil5 编译烧录
     ↓                └───── FPGA?   ──→ quartus 综合→布局→生成.sof
     ↓
[步骤6] 编译烧录 → UV4/JLink / Quartus Programmer
     ↓
[步骤7] 调试方法 → 示波器/串口/GDB/SignalTap 测试步骤
     ↓
[步骤8] 评分点核对 → 逐项检查是否满足评分标准
```

### 3.3 步骤2：方案设计

**系统框图生成原则：**

```mermaid
┌─────────┐    ┌─────────┐    ┌─────────┐
│ 传感器  │───→│ 信号调理 │───→│  ADC   │
│ 输入    │    │ (运放)   │    │        │
└─────────┘    └─────────┘    └───┬─────┘
                                  │
┌─────────┐    ┌─────────┐       ↓
│ 人机交互 │───→│  MCU   │←──┌─────────┐
│ (按键/LED)│   │ 核心控制 │   │ 通信模块 │
└─────────┘    │         │   │ (UART)  │
               │         │   └─────────┘
┌─────────┐    │         │
│ 执行器  │←───│ PWM/DAC │
│ (电机等)│    └─────────┘
└─────────┘
```

**选型三要素：**
1. **TI 指定芯片优先** — 查阅当年芯片推荐列表
2. **引脚兼容性** — 确保 MCU 外设数量够用
3. **留有余量** — IO 口至少预留 20%

### 3.6 步骤5：代码生成

#### 5a. STM32 项目 → CubeMX 生成 HAL 框架 + 用户代码

```bash
# CubeMX2 CLI 一键生成 Keil 工程
run_skill("cubemx", arguments="创建 STM32F103C8T6 项目: USART1+ADC1+TIM2_PWM+GPIO→生成 MDK-ARM V5")
```

生成的 Keil 项目结构:
```
nuedc_test/
├── nuedc_test.ioc2             ← CubeMX2 配置文件
├── Drivers/CMSIS + HAL/        ← HAL 库
├── Inc/ (main.h gpio.h ...)   ← CubeMX 生成的头文件
├── Src/ (main.c gpio.c ...)   ← 在 USER CODE 区写业务逻辑
└── MDK-ARM/nuedc_test.uvprojx  ← Keil 工程 → keil5 编译
```

**main.c 用户代码模板（在 `USER CODE BEGIN/END` 之间写）：**

```c
/* USER CODE BEGIN Includes */
#include "oled.h"
#include "pid.h"
/* USER CODE END Includes */

int main(void)
{
  HAL_Init();
  SystemClock_Config();        // CubeMX 生成的时钟配置
  MX_GPIO_Init();              // CubeMX 生成的 GPIO
  MX_USART1_UART_Init();
  MX_TIM2_Init();              // PWM
  MX_ADC1_Init();

  /* USER CODE BEGIN 2 */
  OLED_Init();
  PID_Init(&pid, 1.0, 0.1, 0.05);
  HAL_TIM_PWM_Start(&htim2, TIM_CHANNEL_1);
  /* USER CODE END 2 */

  while (1)
  {
    /* USER CODE BEGIN 3 */
    uint16_t adc_val = ADC_Read();
    float duty = PID_Compute(&pid, target, adc_val);
    __HAL_TIM_SET_COMPARE(&htim2, TIM_CHANNEL_1, duty);
    OLED_ShowFloat(0, 0, adc_val);
    HAL_Delay(10);
    /* USER CODE END 3 */
  }
}
```

### 4.1 2025年A题：能量回馈的变流器负载试验装置（概要）

> ⚡ **深度详解见 `nuedc-deep-cases.md` → 第一章（约4000字）**

```
╔══════════════════════════════════════════════════╗
║  2025年 A题：能量回馈的变流器负载试验装置       ║
║                                                 ║
║  🎯 核心任务：用两个 Buck-Boost 电路构建        ║
║    能量回馈负载，模拟不同负载特性               ║
║                                                 ║
║  📐 基本要求：                                  ║
║    ① 恒流模式：输出电流连续可调               ║
║    ② 恒压模式：输出电压可调                   ║
║    ③ 能量回馈效率 ≥ 85%                       ║
║                                                 ║
║  ⭐ 发挥部分：                                  ║
║    ① 动态响应时间 < 100μs                     ║
║    ② 可编程负载曲线                           ║
║    ③ 上位机实时显示                           ║
╚══════════════════════════════════════════════════╝
```

**系统框图：**
```
AC-DC(前级) ──→ Buck-Boost 1 ──→ Buck-Boost 2 ──→ DC-AC(回馈)
                  ↑控制              ↑控制
                  │                  │
               ┌──┴──────────────────┴──┐
               │  MCU (TMS320F28027)     │
               │  PWM + ADC + 保护       │
               └──────────┬──────────────┘
                          │ UART
                     ┌────┴────┐
                     │ PC上位机 │
                     └─────────┘
```

**关键接线表：**
```
MCU: TMS320F28027
┌──────────────┬────────┬──────────┬──────────┐
│ 功能          │ MCU脚  │ 对端     │ 对端引脚 │
├──────────────┼────────┼──────────┼──────────┤
│ PWM1A        │ GPIO0  │ Buck1 GW │ Gate     │
│ PWM1B        │ GPIO1  │ Buck1 GW │ Sync     │
│ PWM2A        │ GPIO2  │ Buck2 GW │ Gate     │
│ PWM2B        │ GPIO3  │ Buck2 GW │ Sync     │
│ ADC_IN_A0    │ ADCINA0│ CS1 输出 │ Vout     │
```

## 👀 六、傻子都能看懂的硬件操作指南

### 6.1 杜邦线接线原则（绕线方法）

```
▸ 概念: 杜邦线 = 两端带金属针的彩色电线
▸ 作用: 把两个板子的引脚连起来

怎样算「接好了」:
  ✅ 金属针完全插入排针孔
  ✅ 手拉线不会掉
  ❌ 只插进去一半（虚接）
  ❌ 插歪了把排针弄弯

颜色对照:
  红色 = 正极电源 (3.3V / 5V / VCC)
  黑色 = 负极地线 (GND / 0V)
  其他颜色 = 信号线（随便用，自己记住就行）
```

### 6.3 示波器使用方法

```
┌────────────────────────────────────────────────┐
│  示波器 — 看"电信号长什么样"                      │
│                                                 │
│  第一步：连接探头                                │
│    1. 探头挂到 CH1 通道                         │
│    2. 探头末端的地线夹（鳄鱼夹）夹到板子 GND    │
│    3. 探针（尖尖的金属针）点到测试点            │
│                                                 │
│  第二步：按 Auto Set 按钮                       │
│    → 示波器自动调整显示                          │
│    → 如果没显示，按一下 CH1 MENU 确认通道打开    │
│                                                 │
│  第三步：读波形                                  │
│    横轴 = 时间（看时基，比如 1ms/格）            │
│    纵轴 = 电压（看幅度，比如 1V/格）             │
│                                                 │
│  常用设置速查:                                  │
│  ├─ 测 1kHz 正弦波 → 时基 500μs, 幅度 1V       │
│  ├─ 测 PWM 波形   → 时基 100μs, 幅度 2V        │
│  ├─ 测串口信号    → 时基 100μs, 触发上升沿     │
│  └─ 测电源纹波    → AC 耦合, 时基 10μs, 20mV   │
└────────────────────────────────────────────────┘
```

### 6.4 万用表使用方法

```
┌────────────────────────────────────────────────┐
│  万用表 — 测"电压 / 电流 / 通断"                 │
│                                                 │
│  测电压（并联）：                                │
│    1. 红笔插 VΩ 孔，黑笔插 COM 孔               │
│    2. 旋钮转到 DC V ─── 档                      │
│    3. 红笔点正极，黑笔点负极                    │
│    4. 读数：正常 3.3V 或 5V                     │
│                                                 │
│  测通断（检查线有没有断）：                      │
│    1. 旋钮转到 →))) 蜂鸣档                      │
│    2. 红黑笔分别碰线的两端                       │
│    3. 通了 → "哔——"声                            │
│    4. 没声 → 线断了 / 没接好                     │
│                                                 │
│  测电流（串联）：                                │
│    1. 红笔插 10A 孔（大电流）或 mA 孔           │
│    2. 把万用表串到电路里（断开原电路串进去）     │
│    3. 读数                                        │
│    ❗注意：测电流前先断电接线                    │
│    ❗绝对不能把电流表直接量电池两端（会短路）    │
└────────────────────────────────────────────────┘
```

## 🛠 七、对应赛题类型的模板方案

### 7.1 电源类赛题模板

```
【系统架构】
AC 输入 → EMI滤波 → 整流 → PFC → DC-DC → 输出
                                       ↑
                                  ┌────┴────┐
                                  │ PWM控制  │
                                  │ (MCU)    │
                                  └─────────┘

【关键器件】
- 功率管: IRF540N / IRFP460
- 驱动: IR2101 / TLP250
- 采样: ACS712 / 霍尔电流传感器
- 隔离: ISO124 / AD202

【调试要点】
1. 先不接功率电，测控制板 PWM 波形
2. 空载调输出电压
3. 逐步加载，观察波形
4. 测效率 = Pout / Pin
```

### 7.2 控制类赛题模板

```
【系统架构】
传感器 → 单片机 → 驱动 → 执行器
   ↓        ↑
   └── ADC ─┘

【控制算法选择】
- PID: 电机速度/位置控制
- 模糊控制: 循迹/避障
- 卡尔曼滤波: 传感器融合

【调试顺序】
1. 开环测试每个执行器
2. 单传感器数据读取
3. 闭环控制单变量
4. 多传感器融合
5. 完整任务测试
```

### 7.3 测量/仪器类赛题模板

```
【系统架构】
被测信号 → 调理电路 → ADC → MCU → 显示
   ↑          ↑            ↓
   阻抗匹配   滤波         FFT/算法

【关键参数】
- ADC 采样率 ≥ 信号频率 × 10
- 输入阻抗 ≥ 10kΩ
- 信噪比 SNR ≥ 60dB

【校准方法】
1. 短接输入 → 测零点偏移
2. 输入标准信号 → 测增益误差
3. 软件校准: y = (x - offset) × gain
```
