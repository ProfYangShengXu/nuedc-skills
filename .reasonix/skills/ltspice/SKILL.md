## 🛠 二、CLI 命令速查

| 命令 | 说明 |
|------|------|
| `LTspice.exe -b circuit.asc` | **批处理模式** — 命令行运行仿真，生成 .raw 文件 |
| `LTspice.exe -Run circuit.asc` | 启动 GUI 并运行仿真 |

| `LTspice.exe -wine` | Linux/macOS 通过 Wine 运行提示 |

### 2.1 批处理自动化

```batch
:: run_sim.bat — 一键 LTspice 批处理仿真
:: 注意: -b 批处理模式需要实体 Windows 桌面环境，服务器/容器环境不可用
@echo off
set LT="%LOCALAPPDATA%\Programs\ADI\LTspice\LTspice.exe"

echo [1/2] Running simulation...
%LT% -b buck_converter.cir
if errorlevel 1 goto :error

echo [2/2] Done! Results in buck_converter.raw
echo To view: drag buck_converter.raw onto LTspice.exe
goto :end

:error
echo [ERROR] Simulation failed! Check .log file.
exit /b 1
:end
```

> ⚠️ LTspice 24+ 批处理模式 `-b` 需要实体 Windows 桌面。在 CI/服务器环境中改用 LTspice XVII（旧版）或 ngspice。

## 🔬 四、仿真类型

| 仿真 | 命令 | 电赛场景 |
|------|------|----------|
| **瞬态** | `.tran <step> <stop> [<start>] [<max_step>]` | 时域波形/纹波/开关 |
| **AC 扫描** | `.ac <dec|oct|lin> <N> <fstart> <fstop>` | 频率响应/Bode图 |
| **DC 扫描** | `.dc <source> <start> <stop> <step>` | 直流传输特性 |
| **噪声** | `.noise V(<out>) <src> <dec> <N> <fstart> <fstop>` | 输出噪声谱 |
| **FFT** | `.four <freq> V(<out>)` | 谐波/THD分析 |
| **参数步进** | `.step param <name> <start> <stop> <step>` | 参数优化 |
| **温度** | `.temp <T1> <T2> ...` | 温漂分析 |
| **传递函数** | `.tf V(<out>) <src>` | 小信号特性 |

### 4.1 .meas 测量语句（自动化判分）

```spice
* 平均值
.meas TRAN Vout_avg AVG V(out) FROM 3m TO 5m

* 峰峰值
.meas TRAN Vripple PP V(out) FROM 3m TO 5m

* 最大值
.meas TRAN Vout_max MAX V(out)

* 频率
.meas TRAN freq PARAM 1/(T2-T1) TRIG V(out)=2.5 RISE=1 TARG V(out)=2.5 RISE=2

* 效率
.meas TRAN Pin_avg AVG V(in)*I(V1) FROM 3m TO 5m
.meas TRAN Pout_avg AVG V(out)*I(Rload) FROM 3m TO 5m
.meas TRAN efficiency PARAM 100*Pout_avg/Pin_avg
```

## 🐍 七、Python 自动化

```python
"""gen_ltspice.py — 自动生成 LTspice .asc 文件 (Python)"""

def gen_buck_asc(Vin, Vout, Iout, fsw, filename="buck.asc"):
    """生成 Buck 电路原理图文件"""
    
    asc = f"""Version 4
SHEET 1 880 680
WIRE -16 -80 -112 -80
WIRE 112 -80 -16 -80
WIRE 240 -80 192 -80
WIRE 336 -80 240 -80
WIRE 240 -16 240 -80
WIRE 240 80 240 64
WIRE -112 -16 -112 -80
WIRE 240 176 240 160
WIRE -112 176 -112 64
FLAG -112 176 0
FLAG 240 176 0
SYMBOL voltage -112 -32 R0
SYMATTR InstName V1
SYMATTR Value {Vin}
SYMBOL ind 224 -32 R270
WINDOW 0 32 56 VTop 2
WINDOW 3 5 56 VBottom 2
SYMATTR InstName L1
SYMATTR Value 100µ
SYMBOL cap 224 80 R0
SYMATTR InstName C1
SYMATTR Value 220µ
SYMBOL res 224 144 R0
SYMATTR InstName Rload
SYMATTR Value {Vout/Iout:.1f}
SYMBOL diode 112 -64 R270
WINDOW 0 32 32 VTop 2
WINDOW 3 0 32 VBottom 2
SYMATTR InstName D1
SYMATTR Value MBR745
SYMBOL sw -16 -64 R270
SYMATTR InstName S1
SYMATTR Value MySwitch
TEXT -120 -136 Left 2 ;Buck {Vin}V->{Vout}V @ {Iout}A
TEXT -120 -112 Left 2 ;fsw={fsw}Hz
"""
    with open(filename, 'w') as f:
        f.write(asc)
    print(f"[OK] Generated {filename}")

# 示例
gen_buck_asc(12, 5, 2, 100000)
```

## 🔧 九、常见问题

| 问题 | 解决 |
|------|------|
| "Unknown subcircuit" | 添加 `.lib xxx.sub` 语句加载模型 |
| 仿真不收敛 | 加 `.options gmin=1e-10 abstol=1e-10`；设置 `.ic` 初始条件 |
| 波形显示不出来 | 检查仿真类型是否正确（.tran/.ac 别搞混） |
| .meas 结果为空 | 检查 FROM/TO 时间范围，确保仿真跑到了那个区间 |
| 元件名大小写错误 | SPICE 不区分大小写，但 .subckt 名区分 |
| 输出 .raw 文件太大 | 加 `.save V(out) I(Rload)` 只保存需要的信号 |
